| `phase_dungeon.png` | Phase label badge |
| `phase_arena.png` | Phase label badge |
| `sword_icon.png` | Small icon for weapon slots |
| `armor_icon.png` | Small icon for armor slots |
| `shield_icon.png` | Small icon for off-hand slot |
| `skull_icon.png` | Kill counter icon |
| `timer_icon.png` | Dungeon timer icon |

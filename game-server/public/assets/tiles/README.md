# Tile Assets

Place PNG sprites here (64×64 px recommended).

| Filename | Usage |
|---|---|
| `floor.png` | Standard dungeon floor |
| `floor_cracked.png` | Cracked floor variant |
| `floor_mossy.png` | Mossy floor variant |
| `wall.png` | Stone wall |
| `wall_crack.png` | Cracked wall variant |
| `wall_torch.png` | Wall with torch (animated optional) |
| `door.png` | Room door (open) |
| `boss_entrance.png` | Boss room entrance portal |
| `arena_floor.png` | Arena combat floor |
| `chest.png` | Closed chest |
| `chest_open.png` | Opened chest |

Referenced via `ASSETS.tiles.*` in `types.ts`.
